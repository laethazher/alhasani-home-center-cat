# المرحلة الأولى — أكاديمية الشركة الذكية ومكتبة الفيديو المعرفية

توثيق التغييرات المُضافة إلى منصّة **نظام إدارة المعرفة والامتثال — مجموعة الحسني** ضمن المرحلة الأولى، فوق المعمارية القائمة (Next.js 14 / App Router / Prisma / RTL عربي) دون إعادة بناء.

---

## ١. نظرة عامة

أُضيفت منظومتان جديدتان متكاملتان مع طبقات المصادقة والصلاحيات والتصميم القائمة:

| الوحدة | الوصف |
|---|---|
| **أكاديمية الشركة الذكية** | مسارات تعلّم، دورات بمستويات (مبتدئ/متوسط/متقدّم)، تصنيفات، وحدات ودروس، تتبّع التسجيل والتقدّم، وشهادات. |
| **مكتبة الفيديو المعرفية** | رفع فيديوهات تدريبية وتسجيلات شاشة، تصنيف ووسوم وتصنيف حسب القسم، مكتبة قابلة للبحث، وبحث بالطابع الزمني عبر الفصول. |

كما أُضيف قسم تنظيمي جديد: **اللوجستك** (`LOGISTICS`) إلى جانب الأقسام الأربعة القائمة.

> تعمل كل الشاشات فوراً في **وضع العرض** (`NEXT_PUBLIC_DEMO_MODE=true`) اعتماداً على بيانات نموذجية مرفقة، ودون أي بنية تحتية. مسار الإنتاج موصول بـ Prisma/PostgreSQL وQdrant وMinIO خلف نفس الواجهات.

---

## ٢. تغييرات المعمارية

1. **التوسّع داخل Next.js (المسار أ):** لم يُنشأ خادم NestJS منفصل. أُضيفت النماذج والخدمات ومسارات API والشاشات داخل المشروع نفسه، محافظةً على `getSession`/JWT، ومصفوفة الصلاحيات `ROLE_PERMISSIONS`، ونظام التصميم (Teal `#17B8A1`، خطّا Cairo وIBM Plex Sans Arabic، الوضع الفاتح/الداكن، الشريط الجانبي RTL).

2. **طبقة تجريد مزوّدي التضمين (Embeddings Provider Abstraction):** أُعيدت كتابة `src/lib/ai/embeddings.ts` لتدعم عدّة مزوّدين قابلين للتبديل عبر متغيّر بيئة واحد دون أي تعديل في الكود — تفصيلها في القسم ٧.

3. **جسر كتابة مُصغّر لـ Prisma (`src/lib/db-phase1.ts`):** يُبقي كود مسارات الكتابة قابلاً للفحص النوعي قبل وبعد `prisma generate`، ويُستخدم في مسارات الإنتاج فقط.

4. **الصلاحيات الجديدة:** أُضيفت `course:manage` و`video:manage` و`video:upload` إلى نوع `Permission` ومُنحت لدوري **ADMIN** و**MANAGER** ضمن `ROLE_PERMISSIONS`.

## ٣. تغييرات قاعدة البيانات (Prisma)

أُلحقت بالمخطّط `prisma/schema.prisma` التعدادات والنماذج التالية، مع علاقات عكسية على `User` و`Department`.

### التعدادات (Enums)
`CourseLevel` (BEGINNER/INTERMEDIATE/ADVANCED) · `CourseStatus` (DRAFT/PUBLISHED/ARCHIVED) · `LessonType` (VIDEO/ARTICLE/DOCUMENT/QUIZ) · `EnrollmentStatus` (ENROLLED/IN_PROGRESS/COMPLETED) · `VideoStatus` (PROCESSING/READY/FAILED/ARCHIVED) · `TranscriptStatus` (NONE/PENDING/PROCESSING/COMPLETED/FAILED — مُهيّأ للمرحلة الثانية).

### نماذج الأكاديمية
- **CourseCategory** — تصنيف الدورات (اسم، slug، أيقونة، لون).
- **LearningPath** — مسار تعلّم يربط مجموعة دورات بقسم ومستوى.
- **Course** — الدورة (عنوان، وصف، مستوى، حالة، تصنيف، قسم، مالك، مسار).
- **CourseModule** — وحدة داخل الدورة (تجميع الدروس).
- **Lesson** — درس (نوع، ترتيب، مدّة، ربط اختياري بـ `videoId`/`documentId`).
- **Enrollment** — تسجيل موظّف في دورة (حالة، نسبة تقدّم) — فريد على (userId, courseId).
- **LessonProgress** — تقدّم الدرس لكل تسجيل — فريد على (enrollmentId, lessonId).
- **Certificate** — شهادة إتمام (رقم تسلسلي، درجة) — فريدة على (userId, courseId).

### نماذج مكتبة الفيديو
- **VideoCategory** — تصنيف الفيديو.
- **Video** — الفيديو (ملف، صورة مصغّرة، مدّة، حالة، `tags: String[]`، مشاهدات، تصنيف، قسم، رافع). يحوي حقلَي `transcriptStatus` و`language` **مُهيّأين للمرحلة الثانية**.
- **VideoView** — سجلّ مشاهدة (للتحليلات والاستئناف من آخر موضع).

### علاقات أُضيفت
- `User`: `enrollments`, `certificates`, `ownedCourses`, `uploadedVideos`, `videoViews`.
- `Department`: `courses`, `learningPaths`, `videos`.

> الهجرة على جهازك:
> ```bash
> npm run prisma:generate
> npx prisma migrate dev -n "phase1_academy_video"
> npm run db:seed
> ```

## ٥. واجهات API

| الطريقة | المسار | الوظيفة |
|---|---|---|
| GET | `/api/academy/courses` | قائمة الدورات (مرشّحات: `q`, `level`, `categoryId`, `departmentId`, `mine`). |
| GET | `/api/academy/courses/[id]` | تفاصيل دورة (٤٠٤ إن لم تكن مرئية). |
| POST | `/api/academy/enroll` | تسجيل (`ENROLL`) أو تحديث تقدّم (`PROGRESS`)؛ يُصدر شهادة عند ١٠٠٪. |
| GET | `/api/videos` | قائمة الفيديو (مرشّحات: `q`, `categoryId`, `departmentId`). |
| GET | `/api/videos/[id]` | تفاصيل فيديو. |
| GET | `/api/videos/search?q=` | بحث الفيديو مع إرجاع الطابع الزمني المطابق. |
| POST | `/api/videos/upload` | رفع فيديو (محميّ بـ `video:upload`). |

كل المسارات تتحقّق من الجلسة (٤٠١ بدونها)، وتطبّق الرؤية حسب الدور/القسم، وتستخدم `zod` للتحقّق من المدخلات في عمليات الكتابة.

## ٦. الشاشات (UI)

- **الأكاديمية:** بطاقات مؤشّرات (مسجَّلة/قيد التقدّم/مكتملة/شهادات)، مسارات التعلّم، «أكمل التعلّم»، ودليل الدورات.
- **تفاصيل الدورة:** غلاف وبيانات، زر التسجيل، منهج قابل للطيّ مع تبديل إكمال كل درس، شريط تقدّم، وإشعار الشهادة عند الإكمال. روابط الدروس تنقل إلى الفيديو أو الوثيقة المرتبطة.
- **تعلّمي:** دوراتي المسجَّلة + شهاداتي.
- **مكتبة الفيديو:** شريط بحث لحظي (debounced) يستدعي `/api/videos/search`، مرشّحات التصنيف والقسم، وشبكة بطاقات.
- **مشغّل الفيديو:** مشغّل HTML5، قائمة فصول قابلة للقفز، دعم الرابط العميق `?t=ثوانٍ`، وإشعار بأن النسخ النصي يأتي في المرحلة الثانية.
- **رفع فيديو:** منطقة سحب وإفلات، بيانات وصفية، وسوم تفاعلية، وحماية بالصلاحية.

## ٧. طبقة تجريد مزوّدي التضمين

تُضبط بالكامل عبر البيئة دون تعديل الكود:

```env
EMBEDDINGS_PROVIDER=local        # local | openai | voyage | ollama
EMBEDDING_DIM=1024               # يجب أن يطابق مجموعة Qdrant والمزوّد
```

| المزوّد | المتغيّرات | البُعد الافتراضي |
|---|---|---|
| `openai` | `OPENAI_API_KEY`, `OPENAI_EMBEDDING_MODEL` (افتراضي `text-embedding-3-small`) | 1536 |
| `voyage` | `VOYAGE_API_KEY`, `VOYAGE_EMBEDDING_MODEL` (افتراضي `voyage-3`) | 1024 |
| `ollama` | `OLLAMA_URL`, `OLLAMA_EMBEDDING_MODEL` (افتراضي `nomic-embed-text`) | 768 |
| `local` | — (تضمين حتمي بلا إنترنت ولا مفاتيح) | `EMBEDDING_DIM` |

السلوك:
- `embed(text)` يختار المزوّد من البيئة، ويسقط تلقائياً إلى المحلّي عند أي خطأ.
- في **وضع العرض** يُستخدم التضمين المحلّي دائماً لضمان التشغيل الفوري.
- **إضافة مزوّد مستقبلي:** أضِف دالة جديدة وأدرجها في الخريطة `PROVIDERS` — لا تغييرات في بقية الكود.

> أُحدِّثت دوال Qdrant (`qdrantSearch`/`ensureQdrantCollection`) لاستقبال اسم المجموعة والبُعد، وحُدِّث المساعد المعرفي وسكربت الفهرسة وفقاً لذلك.

## ٨. التشغيل

**وضع العرض (افتراضي — بلا بنية تحتية):**
```bash
npm install
npm run prisma:generate   # يُولّد عميل Prisma (يتضمّن نماذج المرحلة الأولى)
npm run dev
```
ثم سجّل الدخول بأحد مستخدمي العرض (مثل `admin@alhasani.iq` / `Admin@2026`) وافتح **الأكاديمية** و**مكتبة الفيديو** من الشريط الجانبي.

**مسار الإنتاج:** اضبط `NEXT_PUBLIC_DEMO_MODE=false`، وعبّئ متغيّرات قاعدة البيانات وQdrant وMinIO ومزوّد التضمين، ثم نفّذ الهجرة والبذر.

## ٩. المرحلة الثانية (التالية)

- **محرّك النسخ النصي:** استخراج الصوت ⇽ تحويل الكلام إلى نص ⇽ كشف الفصول والمواضيع والإجراءات التشغيلية.
- **تخزين النسخ:** نماذج `VideoTranscript` / `VideoSegment` (الحقول `transcriptStatus` و`language` مُهيّأة على `Video` مسبقاً).
- **بحث النسخ والطابع الزمني الدلالي:** فهرسة المقاطع في Qdrant (مجموعة `video_segments`) عبر طبقة التضمين، وإرجاع الطابع الزمني الأدقّ ضمن نتائج البحث.
