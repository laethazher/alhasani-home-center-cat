# منصة إدارة المعرفة والامتثال — مجموعة الحسني
### Al-Hasani Group · Knowledge & Compliance Platform

منصّة داخلية لإدارة الوثائق الرسمية (الكتب الإدارية، التعاميم، التبليغات، السياسات، التعليمات، وإجراءات العمل)، مع بحث ذكي داخل نص الـ PDF، ومساعد معرفي بالذكاء الاصطناعي يجيب من الوثائق المعتمدة حصراً، ونظام متكامل لتتبّع الاطّلاع والإقرار والامتثال.

> **المكدّس:** Next.js 14 (App Router) · TypeScript · Tailwind CSS · PostgreSQL + Prisma · Elasticsearch · Qdrant · OCR · JWT · RBAC — مع واجهة عربية RTL تنفيذية ووضعين ليلي/نهاري.

## ✦ التشغيل السريع (وضع العرض — دون أي بنية تحتية)

التطبيق يعمل فوراً ببيانات عربية مدمجة ومصادقة عبر حسابات تجريبية — **بلا PostgreSQL أو غيره**.

```bash
npm install
cp .env.example .env      # القيم الافتراضية كافية لوضع العرض
npm run dev               # http://localhost:3000
```

**حسابات تجريبية** (تظهر أيضاً في شاشة الدخول مع تعبئة بنقرة):

| الدور | البريد | كلمة المرور |
|---|---|---|
| مدير النظام | `admin@alhasani.iq` | `Admin@2026` |
| مدير قسم | `n.inventory@alhasani.iq` | `Manager@2026` |
| موظف | `a.faleh@alhasani.iq` | `Employee@2026` |

> المساعد المعرفي يعرض المصادر المسترجَعة في وضع العرض؛ ولتفعيل الإجابات المولّدة بالكامل أضِف `ANTHROPIC_API_KEY` إلى `.env` (يعمل في الوضعين).

## ✦ التشغيل في الإنتاج (المكدّس الكامل)

```bash
# 1) شغّل البنية التحتية (PostgreSQL + Elasticsearch + Qdrant + MinIO)
docker compose up -d

# 2) فعّل مسار الإنتاج
#    في .env اضبط: NEXT_PUBLIC_DEMO_MODE=false  + ANTHROPIC_API_KEY=...  + JWT_SECRET قويّ

# 3) قاعدة البيانات والبيانات الأولية
npm run prisma:generate
npm run prisma:push        # أو prisma:migrate لإنشاء هجرات
npm run db:seed            # أقسام + مستخدمون (كلمات مرور مُجزّأة) + وثائق + SOP + اختبار

# 4) بناء فهارس البحث
npm run search:index       # Elasticsearch (نصي) + Qdrant (دلالي)

# 5) التشغيل
npm run dev                # أو: npm run build && npm start
```

> **OCR:** الواجهة جاهزة (`src/lib/ocr/ocrService.ts`). للتفعيل على خادم ذاتي ثبّت `tesseract-ocr` (حزم `ara`+`eng`) و`poppler`، أو اضبط `OCR_PROVIDER=azure` مع مفاتيح Azure Document Intelligence.

## ✦ ملاحظات معمارية

- **مصدر الحقيقة** هو PostgreSQL؛ Elasticsearch وQdrant فهارس مشتقّة تُعاد بناؤها من قاعدة البيانات.
- **نمط المحوّل + التدهور اللطيف:** كل خدمة خارجية خلف واجهة مع بديل محلي، فلا ينهار التطبيق عند غياب خدمة.
- **الخطوط** تُحمَّل عبر Google Fonts (`@import` في `globals.css`) لتفادي الاعتماد على الشبكة وقت البناء.
- **الأمان:** JWT (HttpOnly cookie) · bcrypt · RBAC مركزي · رؤية صفّية حسب القسم/الحالة/السرية.

هذه هي **المرحلة الأولى (الأساس الإنتاجي)**: واجهة كاملة قابلة للتشغيل فوراً + كامل بنية الخادم والخدمات. ربط البيانات الحيّة موثّق ضمن `lib/data/repository.ts` (استعلامات Prisma)، وسلسلة الـ OCR في `lib/ocr/ocrService.ts`، وسكربت الفهرسة في `scripts/reindex.ts`.
