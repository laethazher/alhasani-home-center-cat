# رفع التحديثات تلقائياً إلى GitHub دون طلب موافقة

---

## ماذا يعني "10 Files" في Source Control؟ وكيف أُثبّت التغييرات بشكل كامل؟

**التغييرات المعلقة (Pending Changes)** = ملفات غُيّرت على جهازك لكن لم تُحفظ بعد في سجل Git (commit) ولم تُرفع إلى GitHub.

### خطوات جعل التغيير «مثبتاً بشكل كامل» (Stage → Commit → Push)

1. **احفظ كل الملفات أولاً**  
   إذا كانت التغييرات فقط داخل المحرر ولم تُحفظ على القرص، لن يراها Git.  
   - من القائمة: **File → Save All**  
   - أو اختصار: **`Ctrl + K` ثم `S`** (احفظ الكل)

2. **تحضير التغييرات (Stage)**  
   - في لوحة **Source Control** (أيقونة الفرع/Git في الشريط الجانبي): اضغط **+** بجانب "Changes" لتحضير كل الملفات، أو **+** بجانب كل ملف على حدة.

3. **تأكيد التغييرات (Commit)**  
   - اكتب رسالة commit في الصندوق أعلى اللوحة (مثل: `تحديثات واجهة المركبات وإصلاح الاستيراد`).  
   - اضغط زر **Commit** (أو ✓).

4. **رفع التغييرات (Push)**  
   - بعد الـ commit اضغط زر **Push** (أو السهم لأعلى ↑) لرفع التغييرات إلى GitHub.

### من الطرفية (Terminal) دفعة واحدة

إذا حفظت الملفات وترغب في تثبيت ورفع كل التغييرات بأمر واحد:

```bash
git add -A && git commit -m "تحديثات المشروع" && git push origin main
```

استبدل `تحديثات المشروع` برسالة مناسبة تصف التعديلات.

## تفعيل الرفع التلقائي دون موافقة

حتى يستطيع المساعد (Agent) تنفيذ `git add` و `git commit` و `git push` **مباشرة دون أن يطلب منك الموافقة** في كل مرة، غيّر إعدادات Cursor كالتالي:

---

## الطريقة 1 (موصى بها): تشغيل كل الأوامر تلقائياً

1. افتح **إعدادات Cursor**: `Ctrl + ,` (أو من القائمة: File → Preferences → Cursor Settings).
2. ابحث عن **Agent** أو **Auto-Run**.
3. في قسم **Auto-run mode** اختر:
   - **Run Everything**  
   = يشغّل المساعد كل الأوامر والأدوات تلقائياً **بدون طلب موافقتك**.

بهذا الشكل لن يُطلب منك تأكيد عند تنفيذ `git push` أو غيره.

---

## الطريقة 2: السماح فقط لأوامر Git

إذا أردت أن تبقى الموافقة مطلوبة لمعظم الأوامر، لكن **بدون موافقة لـ git فقط**:

1. افتح **Cursor Settings** → **Agents** → **Auto-Run**.
2. في **Command Allowlist** (قائمة الأوامر المسموحة) أضف أو تأكد من وجود:
   - `git add`
   - `git commit`
   - `git push`
   - أو نمط عام مثل `git`

بحسب واجهة Cursor، قد تكون الصيغة مثل: `git push` أو `git*`.

---

## إعداد المشروع الحالي

- تم وضع ملف **`.cursor/sandbox.json`** في المشروع يسمح بالاتصال بالشبكة داخل الـ sandbox (مثل الاتصال بـ GitHub عند `git push`).
- بعد تفعيل **Run Everything** أو إضافة أوامر git إلى **Command Allowlist**، يمكن للمساعد رفع التحديثات إلى GitHub مباشرة دون أن يطلب منك الموافقة أو الرفع اليدوي.
