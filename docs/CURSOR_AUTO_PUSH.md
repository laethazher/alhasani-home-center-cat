# رفع التحديثات تلقائياً إلى GitHub دون طلب موافقة

حتى يستطيع المساعد (Agent) تنفيذ `git add` و `git commit` و `git push` **مباشرة دون أن يطلب منك الموافقة** في كل مرة، غيّر إعدادات Cursor كالتالي:

---

## الطريقة 1 (موصى بها): تشغيل كل الأوامر تلقائياً

1. افتح **إعدادات Cursor**: `Ctrl + ,` (أو من القائمة: File → Preferences → Cursor Settings).
2. ابحث عن **Agent** أو **Auto-Run**.
3. في قسم **Auto-run mode** اختر:
   - **Run Everything**  
   = يشغّل المساعد كل الأوامر والأدوات تلقائياً **بدون طلب موافقتك**.

بهذا الشكل لن يُطلب منك تأكيد عند تنفيذ `git push` أو غيره.

---

## الطريقة 2: السماح فقط لأوامر Git

إذا أردت أن تبقى الموافقة مطلوبة لمعظم الأوامر، لكن **بدون موافقة لـ git فقط**:

1. افتح **Cursor Settings** → **Agents** → **Auto-Run**.
2. في **Command Allowlist** (قائمة الأوامر المسموحة) أضف أو تأكد من وجود:
   - `git add`
   - `git commit`
   - `git push`
   - أو نمط عام مثل `git`

بحسب واجهة Cursor، قد تكون الصيغة مثل: `git push` أو `git*`.

---

## إعداد المشروع الحالي

- تم وضع ملف **`.cursor/sandbox.json`** في المشروع يسمح بالاتصال بالشبكة داخل الـ sandbox (مثل الاتصال بـ GitHub عند `git push`).
- بعد تفعيل **Run Everything** أو إضافة أوامر git إلى **Command Allowlist**، يمكن للمساعد رفع التحديثات إلى GitHub مباشرة دون أن يطلب منك الموافقة أو الرفع اليدوي.
